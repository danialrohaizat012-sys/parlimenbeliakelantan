# MANDAT Kelantan | Portal Maklumat

Laman statik HTML/CSS/JavaScript untuk maklumat calon, bidang dasar, program pendidikan dan FAQ Parlimen Belia Malaysia.

## Deploy ke GitHub Pages

1. Dalam repository, buka **Settings → Pages**.
2. Pilih **Build and deployment → Deploy from a branch**.
3. Pilih branch **main** dan folder **/(root)**, kemudian klik **Save**.
4. Tunggu GitHub Pages memaparkan URL penerbitan.

## Aset logo

Muat naik fail **mandat-logo.webp** daripada pakej website V1.1 ke root repository supaya logo rasmi dipaparkan di navbar dan homepage. HTML mempunyai fallback teks sementara logo belum dimuat naik.

## Semakan sebelum penerbitan

- Sahkan nama dan susunan 14 calon dengan ePBMy.
- Gantikan kandungan dasar contoh dengan manifesto yang diluluskan.
- Masukkan jadual program hanya setelah disahkan.
- Semak semula kandungan dan paparan mobile sebelum berkongsi URL.

Website ini bukan portal rasmi Parlimen Malaysia. Rujukan rasmi: https://epbmy.parlimen.gov.my/.
